# GDPS EDITOR 2.3 — интерфейс 0.2
Самостоятельный браузерный прототип интерфейса: заставка загрузки, главная, библиотека уровней, редактор, профиль и настройки.

Запуск: открыть index.html в современном браузере.

Редактор умеет размещать шесть видов объектов, выбирать и удалять их, менять координаты, переключать сетку и фон, отменять/повторять действия, импортировать и экспортировать JSON. Проекты сохраняются локально в браузере.

Это UI-прототип, не готовая Android-сборка. Онлайн-аккаунты, публикация, игровая физика и runtime пока не реализованы.
