# GDPS EDITOR 2.3 — интерфейсный прототип

Это отдельный оригинальный прототип редактора уровней. Он не заменяет старые исходники и пока не подключён к Android/C++ приложению.

## Запуск
Откройте `index.html` в современном браузере.

## Уже работает
- адаптивная тёмная фиолетовая оболочка редактора;
- поле уровня с сеткой;
- добавление блоков, шипов, платформ, сфер, порталов и пил;
- выбор и удаление объектов;
- изменение координат;
- отмена и повтор действий;
- выбор фона;
- импорт и экспорт уровня в JSON.

## Следующие этапы

2. Добавить перетаскивание объектов и масштабирование камеры без CSS-трансформации.

4. Написать отдельный игровой runtime и физику.
